# Image Smoothing & Sharpening using DSP Filters

A web-based Digital Signal Processing (DSP) project that demonstrates image smoothing, sharpening, and edge detection using Mean, Gaussian, and Laplacian filters.

---

# Project Description

This project applies different spatial domain filtering techniques to grayscale/color images and compares their effects on noise reduction and edge enhancement.

The application is developed using **Python, Flask, and OpenCV** and provides an interactive user interface for uploading images and visualizing processed outputs along with histograms.

# DSP Concepts Used

- **Mean Filter**  
  A low-pass filter used for noise reduction through averaging of neighboring pixels.

- **Gaussian Filter**  
  A low-pass smoothing filter that reduces noise while preserving edges more effectively.

- **Laplacian Filter**  
  A high-pass filter used for edge detection and image sharpening by identifying rapid intensity changes.
